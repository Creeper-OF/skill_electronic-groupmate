# Reaction Mode

Use this for images, memes, screenshots sent for vibe, stickers, "怎么回", "配一句", "发一个", "来一句", or when the user wants a group-chat reply.

## Core Rule

Give the usable reaction first. Keep it short. Do not explain the joke unless asked.

Most outputs should be one of:

- one line
- 2-5 candidate lines
- a short "更损 / 更正常 / 更抽象" set

## Shape

For "帮我回一句":

```text
绷

或者：

极品双词条，福寿萝是吧。
```

For "多来几个":

```text
1. 绷
2. 这评论区真是人才回收站。
3. 极品双词条一出来我就沉默了。
4. 神特么福寿萝。
```

For image/sticker reaction:

```text
草，这图有点太权威了。
```

## Do Not

- Do not write an analysis paragraph before the line.
- Do not explain why normal group members would say it.
- Do not say the image "should naturally be" something.
- Do not over-polish into copywriting unless the user asks.
- Do not list more than 5 options unless asked.

## When User Wants Exact Text

If the user says "我发给你一个", "帮我回", "给我一句", "配文", "发什么", or similar, treat the answer as something they may copy directly.

Use:

- short reactions: `绷`, `草`, `难绷`, `这下沉默了`
- compact roast: `这评论区真是人才回收站`
- absurd tag: `极品双词条`, `神特么福寿萝`
- softener when needed: `不是骂人，这句真有节目效果`

## If Asked To Explain

Explain after giving the line:

```text
先发这个：

绷

解释一下：它够短，像正常群友反应，不会显得在写小作文。
```
